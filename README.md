# Сайт подготовки к ЕГЭ по обществознанию — Арина Мельситова

Современный редизайн сайта. Чистый HTML + CSS + JavaScript, без сборки и зависимостей —
можно открыть локально или залить на любой хостинг как статику.

## Структура

```
index.html                  — главная (все секции)
otzyvy.html                 — отзывы учеников (3 слайдера)
socialnaya-programma.html   — социальная программа
assets/
  css/style.css             — вся стилистика и дизайн-система (переменные в :root)
  js/main.js                — анимации, слайдер, обработчик формы (+ интеграция Bitrix)
  img/                       — все изображения (взяты с исходного сайта)
    reviews/                 — скриншоты отзывов
```

## Как запустить локально

```bash
python3 -m http.server 8777
```
Затем открыть http://localhost:8777

## Перестановка блоков

Каждая секция главной — самостоятельный `<section>` с комментарием-меткой вида
`<!-- BLOCK: features -->`. Чтобы поменять порядок — просто вырежьте нужный
`<section>...</section>` целиком и вставьте в другое место. Стили не завязаны на
порядок следования (никаких `nth-child` между секциями), поэтому ничего не сломается.

Список блоков главной: `hero`, `features`, `stats`, `steps`, `life`, `roadmap`,
`about`, `pricing`, `result`, `form`.

## Изменение цветов и шрифтов

Все токены — в начале `assets/css/style.css`, в блоке `:root` (цвета, шрифты,
скругления, тени). Меняете переменную — меняется весь сайт.

## Подключение CRM Bitrix24

Форма заявки уже подготовлена. Точка интеграции — в `assets/js/main.js`
(большой комментарий «ФОРМА ЗАЯВКИ — точка интеграции с Bitrix24 CRM»).

**Вариант А — входящий вебхук (создание лида):**
1. В Bitrix24 создайте вебхук с правом `crm.lead.add`.
2. Вставьте его URL в константу `BITRIX_WEBHOOK_URL` в `main.js`.
3. Готово — заявки будут падать в CRM как лиды. Поля формы уже названы под CRM
   (`NAME`, `PHONE`, `CHANNEL`, `FORMAT`).

**Вариант Б — готовая CRM-форма Bitrix24 (встроенный скрипт):**
Замените `<form id="lead-form">…</form>` в `index.html` на код виджета формы,
который выдаёт Bitrix24. Тогда обработчик в `main.js` не нужен.

Пока вебхук не задан, форма работает в демо-режиме (показывает благодарность,
данные пишет в консоль браузера).

## Что сделано в редизайне

- Современная типографика: Playfair Display (заголовки) + Manrope (текст).
- Тёплая палитра исходника (крем/терракота/эспрессо/золото), но аккуратная сетка.
- Анимации: параллакс hero, появление секций при скролле, счётчики цифр,
  прорисовка линии таймлайна, hover-эффекты карточек, стеклянный хедер,
  прогресс-бар прокрутки, кастомный слайдер отзывов со свайпом.
- Адаптив под телефоны и планшеты, поддержка `prefers-reduced-motion`.
- Прогрессивное улучшение: без JS весь контент остаётся видимым.

Весь текст и смысловое наполнение сохранены с оригинального сайта.
